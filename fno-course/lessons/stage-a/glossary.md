# Stage A Glossary

Alphabetical. Terms are explained in the context of the Indian F&O market.

| Term | Meaning |
|---|---|
| **Algo (algorithmic) trading** | Orders generated and/or placed automatically by software following rules. Regulated by SEBI's retail algo framework **[VERIFY]**. |
| **Ask / Offer** | The lowest price at which a seller is willing to sell. You buy at the ask. |
| **ATM / ITM / OTM** | At / In / Out of the money: strike relative to spot. A call is ITM if spot > strike; a put is ITM if spot < strike. |
| **Backwardation** | Futures price below spot (or near contract below far contract). Unusual for indices. |
| **Basis** | Future price − spot price. |
| **Bid** | The highest price a buyer is willing to pay. You sell at the bid. |
| **Bid-ask spread** | Ask − bid. A direct trading cost. |
| **Bracket / Cover order** | An entry bundled with stop-loss (and target). Availability has been restricted **[VERIFY]**. |
| **Broker (trading member)** | Intermediary giving you access to the exchange, holding margin, charging brokerage. |
| **Call option** | Right (not obligation) to buy the underlying at the strike on/before expiry. In India: European style (exercisable at expiry). |
| **Circuit breaker** | Mechanism that halts trading when an index moves by 10%, 15% or 20%; stock-level bands also exist. |
| **Clearing corporation** | Entity (e.g., NSE Clearing) that guarantees trades, collects margin, settles money. |
| **Contango** | Futures price above spot. Normal state for indices. |
| **Contract note** | Broker's document listing trades and charges for a day. |
| **Cost of carry** | Net cost of holding the underlying until expiry (interest minus dividends). Drives fair futures price. |
| **Demat account** | Electronic account holding securities, with a depository participant. |
| **Depository** | CDSL or NSDL: holds securities electronically. |
| **Derivative** | Contract whose value is derived from an underlying. |
| **ELM (Extreme Loss Margin)** | Margin component covering tail moves; raised on expiry day for short options **[VERIFY]**. |
| **Exposure margin** | Extra margin on top of SPAN. |
| **European option** | Exercisable only at expiry. |
| **Expiry** | Date a contract ceases to exist and is settled. |
| **F&O ban** | Period when a stock's OI exceeds 95% of the market-wide position limit; only position-reducing trades allowed. |
| **Fair value (future)** | Spot × e^((r − q)T). |
| **Freeze quantity** | Max quantity per order allowed by the exchange; larger orders are rejected. |
| **Future** | Standardised, exchange-traded agreement to buy/sell an underlying at a set price on a set date. |
| **GST** | Goods and services tax (18%) on brokerage and certain charges. |
| **GTT** | "Good till triggered": a broker-side order that persists across days. |
| **IOC** | Immediate or cancel. |
| **Intrinsic value** | What an option would be worth if exercised now: max(S − K, 0) for calls, max(K − S, 0) for puts. |
| **Iron condor** | Four-leg defined-risk option structure that profits if the underlying stays within a range. |
| **ITR-3** | Income tax return form typically used for business income including F&O. |
| **Leverage** | Notional value ÷ margin. |
| **Limit order** | Order to trade at a specified price or better. |
| **Lot size** | Minimum tradeable quantity of a contract. |
| **LTP** | Last traded price. |
| **Margin** | Collateral required to hold a position. |
| **Mark-to-market (MTM)** | Daily revaluation and cash settlement of futures (and short-option) P&L to the settlement price. |
| **Market order** | Order to trade immediately at the best available price(s). |
| **Mid price** | (Bid + ask) / 2. |
| **Notional (contract) value** | Price × lot size (for options on the index, strike or index level × lot size). |
| **Novation** | Replacement of the original counterparties by the clearing corporation. |
| **NSE / BSE** | National Stock Exchange / Bombay Stock Exchange. |
| **Open interest (OI)** | Number of contracts outstanding. |
| **Order book** | List of all resting buy and sell orders by price. |
| **Peak margin** | The maximum margin requirement at any time during the day, reported to the clearing corporation. |
| **Physical settlement** | Delivery of the underlying shares at expiry (stock F&O in India). |
| **Premium** | Price of an option. |
| **Price-time priority** | Matching rule: best price first, then earliest order. |
| **Put option** | Right to sell the underlying at the strike. |
| **Rollover** | Closing a near-expiry position and opening the same position in the next expiry. |
| **SCORES** | SEBI's complaint redress system. |
| **SEBI** | Securities and Exchange Board of India, the market regulator. |
| **Settlement price** | Exchange-determined price used for daily MTM and final settlement. |
| **Slippage** | Difference between expected and actual execution price. |
| **SL / SL-M** | Stop-loss limit / stop-loss market order. |
| **SPAN margin** | Risk-based margin from a worst-case scenario analysis of the portfolio. |
| **Strike** | Price at which an option can be exercised. |
| **STT** | Securities Transaction Tax: charged on the sell side for F&O. |
| **Tick size** | Smallest allowed price increment. |
| **T+1** | Settlement one working day after the trade (cash equity). |
| **Time value** | Option premium minus intrinsic value. |
| **Turnover (tax)** | For F&O, based on the absolute sum of profits and losses per ICAI guidance; determines tax audit applicability. |
| **Underlying** | The asset a derivative is based on. |
| **Volume** | Contracts traded during a period. |
| **Writer** | Seller of an option. |
